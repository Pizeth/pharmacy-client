# Homepage effects

Inspired by [Kan3an's interactive portfolio](https://codepen.io/Kan3an/pen/pvyXbNa).
The existing hero gains a moving grid, scan line and soft title glow. Document and resource links
gain a secondary-colored border glow, a small lift and a passing sheen on hover
or keyboard focus. The gallery keeps its independent scrolling and flip behavior.

Presentation stays in the existing named `RazethHrd` slots.
Theme colors and typography remain authoritative. Decorative elements ignore
pointer input and are hidden from assistive technology. Reduced motion disables
the animations and hover lift.
